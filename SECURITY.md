# Security

## Reporting a vulnerability

If you find a security problem in the getclean API or in this contract, write to security@getclean.ai. Please do not open a public issue for it.

Tell us what you can: what you called, the steps that show the problem, and what someone could gain from it. A proof of concept helps. Do not run an exploit against the live service.

You will hear back within three working days, and you will get a first assessment within ten. We keep you informed while we work on a fix and tell you when it ships. We ask for 90 days before you publish anything about the problem, or until the fix is released, whichever comes first.

You can also report privately through GitHub's private vulnerability reporting, under the Security tab of this repository.

## Scope

This policy covers the getclean API and the contract in this repository. A problem in an official SDK is reported the same way, or through that SDK repository's own security policy.
